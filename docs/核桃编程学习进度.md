## 三、已掌握知识点（按课次）

### L1-2：if 语句 / 变量 / 关系运算符

- **if 语句**：条件控制语句，用于判断
  - 条件成立 → 执行大括号 `{}` 内代码
  - 条件不成立 → 跳过
  - 结构：`if (条件) { 代码 }`
- **单 if 语句**：只有一个判断
- **并列 if 语句**：多个 if 一个接一个，从上到下依次判断，互相之间无数理关系
- **变量**：带名字的容器（盒子），值可变，新值覆盖旧值
  - 使用三步：`int a;`（定义）→ `cin >> a;`（输入）→ `cout << a;`（输出）
- **关系运算符**（6 个）：`>` 大于、`<` 小于、`==` 等于、`>=` 大于等于、`<=` 小于等于、`!=` 不等于
  - 注意：判断"等于"用 `==`，不是 `=`
- **关系表达式**：写在 if 括号里的判断条件，如 `b>5`、`a<7`、`b==7`

### L1-3：for 语句（核心）

- **for 语句作用**：重复执行某段代码（循环结构）
- **语法格式**：`for (变量初始化; 循环条件; 步长) { 重复执行的代码 }`
- **for 三要素**（重点）：
  - `int i=1`：循环初始化，开始循环前新建变量 i 并赋初始值
  - `i<=7`：循环条件（重点中的重点），每次重复前判断 i 是否符合条件，符合就执行
  - `i++`：步长，每次重复后 i 增加 1（i 每次变动的值）
- **执行流程**：初始化 → 判断条件 → 成立则执行代码 → 步长 → 回到判断条件 → 不成立则结束
- **顺序执行中的 for**（重难点）：
  - 从第一行代码开始，依次向下读，直到 `return 0` 结束
  - 遇到 if：看条件，成立才执行大括号内代码，然后继续向下
  - 遇到 for：先看大括号要重复什么，再看小括号定的重复次数
  - 示例代码：
    ```cpp
    int a;
    cin >> a;
    if(a<5) { cout << "g" << endl; }
    cout << "tr" << endl;
    for(int i=1; i<=3; i++) {
        cout << "f" << endl;
        cout << "d" << endl;
    }
    ```

### L1-4：智能门铃 & 语音留言（指令类）

- **检测按钮**：
  - `isPressed("A")`：判断按钮是否被按下，括号内填按钮名称，名称要加双引号
  - `playSound("ring")`：播放声音，括号内填声音名称，要加双引号
  - 示例：`if(isPressed("A")) { playSound("ring"); }`
- **打印文字**：
  - `printPos("文字")`：在智慧核心左上角打印文字
  - `printPos("内容", "位置")`：在指定位置打印（前=内容，后=位置，如"中间"）
- **检测触摸传感器**：
  - `isTouched()`：有人按下→条件成立，反之不成立
  - 示例：`if(isTouched()) { printPos("按下"); }`
- **访客留言**：
  - `record()`：录制声音
  - `playSound()`：播放声音

### L2-1：逻辑运算符 && / ||（核心 + 赛考重点）

- **逻辑与 `&&`（与）**：
  - 规则：左右两边条件**都成立**，整个条件才成立
  - 口诀：与要"都"
  - 示例 `if(a>10 && b>10)`：
    - a=12,b=20 → 成立
    - a=3,b=20 → 不成立
    - a=9,b=9 → 不成立
    - a=11,b=9 → 不成立
- **逻辑或 `||`（或）**：
  - 规则：左右两边只要**有一个成立**（一个或两个），整个条件就成立
  - 口诀：或要"有"
  - 注意：①其中一个条件成立则整体成立 ②两个都不成立则整体不成立
  - 示例 `if(a>10 || b>10)`：
    - a=17,b=18 → 成立
    - a=7,b=15 → 成立
    - a=7,b=8 → 不成立
    - a=11,b=9 → 成立
- **数学连接**（哥哥重点）：
  - 编程 `&&` ↔ 数学"且"（∧）
  - 编程 `||` ↔ 数学"或"（∨）
  - 应用：不等式组（如 x>3 ∧ x<5）、几何证明条件组合（如"平行四边形 且 有一个直角"是矩形）

- `cin >> a >> b;` 连续输入：先写的变量先拿到数字

### L3-1：模块17 多变量运算 & 模块18 多 if 找最大值（已学）

- **多变量的输入与输出**：同一行新建多个变量 `int a,b,c;`（逗号隔开）；只写一个 cin，用两个大于号隔开 `cin>>a>>b>>c;`，程序按**从左到右**的顺序把输入的数字装进变量；输出按**从上到下**顺序，**改变 cout 语句的顺序就能改变输出内容的顺序**
- **多变量运算**：`ans=a+b;`、`ans=a*2+b+c*3;` —— 按**先乘除后加减**先算等号右边，再把结果赋值给左边（先算 a*2 和 c*3，最后相加）
- **多 if 找最大值（"擂台法"，重点 ⭐）**：max 是擂主，之后每个选手都跟擂主 PK，比擂主大就成为新擂主（`max=b;`），最后的擂主就是最大值
  ```cpp
  int a,b,c; cin>>a>>b>>c;
  int max; max=a;              // a 先当擂主
  cout<<max<<endl;             // ①
  if(b>max){ max=b; }          // b 挑战
  cout<<max<<endl;             // ②
  if(c>max){ max=c; }          // c 挑战
  cout<<max<<endl;             // ③
  ```
  - 课堂原题：输入 153、410、109 → ①②③ 输出 **153、410、410**（109 打不过 410，max 不变）

### L3-2：模块19 for 语句应用 & 模块20 初识嵌套结构（最新已学 ⭐）

- **循环输入输出**：把 `cin>>a; cout<<a+5<<endl;` 当成一"组"放进 for → 发生多次输入和输出，每轮"先输入→计算→再输出"
- **循环与变量累加**：`a=a+1` 放进 for 跑 5 次，a 一步步长大；**初始化的值不一样，输出结果也不一样**（初值 2 → 输出 3~7；初值 0 → 输出 1~5）；初始值可以是任意数或另一个变量
- **赋值多种形式效果相同**：a=a+10、a=a+1+9、a=a+2*5 效果一样；**有算式先算右边再赋值，先乘除后加减**
- **if 嵌套 for 执行顺序**（重难点）：代码从上到下；一旦进入大括号（不管 if 还是 for 的），**必须把括号内代码全部运行完**才能继续向下
  - if 大括号外的语句：无论条件是否成立都执行（必执行）
  - if 大括号内：只有条件成立才执行
  - 辨析 `cout<<"d"` 在三个位置的输出（if(a>5) + for×4 印 f，前有 f 后有 p）：满足条件时 ①for里面→fcufdfdfdfdp ②两层大括号中间→fcuffffdp ③if外面→fcuffffdp；不满足时 ①fp ②fp ③**fdp**
  - 课堂原题：a=25，`if(a>20){ cout<<"f"; for×3{ cout<<"j"; cout<<"p"; } } cout<<"d";` → **fjpjpjpd**

### L3-3：初识 if 嵌套 & 嵌套结构强化（最新已学 ⭐，2026-07-16 上课，作业满分 🏆）

> 课堂知识总结四大块（据讲义"知识总结"页 + 哥哥课堂笔记 L3-3）：

- **① 循环输入 & 变量累加**：在 for 循环里用 cin 语句，达到多次输入不同数值；每轮"先输入 → 累加 → 再输出"
  ```cpp
  int sum=0;
  int a;
  for(int i=1;i<=3;i++)
  {
      cin>>a;
      sum=sum+a;
      cout<<sum<<endl;
  }
  ```
  - 课堂原题追踪：第1次输入1，a是1，sum=0+1，输出1；第2次输入2，sum=1+2，输出3；第3次输入4，sum=3+4，输出**7**
  - **sum=sum+a 可以简写成 sum+=a**，功能不变
- **② if 嵌套 if**：if 语句是一个**整体**，根据小括号中的**条件是否成立**，决定是否执行大括号里的内容；if 大括号中的 if **也应该看作一个整体**，按顺序执行到这条 if 时，也要根据条件判断是否执行它的大括号
  - 课堂原题：输入 a=25、b=15，`if(a>20){ cout<<"p"<<endl; if(b<20){ cout<<"w"<<endl; } cout<<"c"<<endl; }` → 依次输出 **p、w、c**
  - 关键位置感：`cout<<"c"` 在内层 if 的**外面**、外层 if 的**里面**——只要进了外层大括号，p 和 c 必印，w 只在 b<20 时印
- **③ if-else 嵌套 if-else**：if 语句是**选择结构**，选择执行一部分之后就**结束**了，**不会每个部分都执行**；看到复杂的 if 语句时，要关注**每一个 if 语句在哪些大括号之间做选择**
  - 课堂原题：a>20 成立进外层 → 内层 if(b>20) 不成立、跳过 → 走内层 else → 输出 **w**；外层 else 的 "rh" 整个不看
- **④ 循环输出 i 的值**：`for(int i=2;i<=5;i++){ cout<<i<<endl; }` → i 从 2 开始每次循环自增 1，i 是 2,3,4,5 时条件成立各执行一次 → 输出 **2,3,4,5**；**改变 for 语句中 i 的初始值和判断条件，可以输出任意一段连续的整数**
