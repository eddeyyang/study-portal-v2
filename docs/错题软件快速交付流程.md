# 错题软件快速交付流程

目标：已经做好的试卷/错题软件，不再重新设计平台；在 15–25 分钟内完成隐私分流、归档、验证和交付。

## 先决定一种交付方式

- `Private`：含原卷、分数、批改痕迹、手写内容。只进入 `local-data/mistake-apps/`，由 `mistakes.html?who=...` 本机导入，永不提交。
- `Public`：只含匿名知识点、错因、趋势和迁移练习。放进 `apps/`，登记 `data/mistake-archives.json`，档案页直接打开。

不要先搭用户没要求的新后台或同步系统。已有软件优先复用已经验证好的产品结构，只做必要的脱敏、命名、登记和验证。

快速交付不等于降低审美。漂亮、清晰、儿童友好的视觉结构本身就是需求：主次层级、留白、主题色、卡片关系、动效节奏、手机触控和整卷到单题的阅读路径都必须保留。提速只能来自复用成熟设计、自动化登记和减少返工，不能来自做丑、做简陋或省略视觉 QA。

## 固定时间盒

1. 0–2 分钟：确认孩子、学科、标题、最终入口。
2. 2–5 分钟：同步 `origin/main`，完成文字扫描和逐张图片检查。
3. 5–12 分钟：复用成熟视觉与交互结构，只做必要修改；不添加用户没要求的后台、同步或统计功能。
4. 12–18 分钟：运行快速通道脚本，完成复制与索引登记。
5. 18–25 分钟：验证首页入口、档案入口、核心错题解析、手机布局、视觉完成度和线上 200。

图像编辑超过一次正常等待仍无结果，立即停止重复等待并报告具体阻塞。Git HTTPS 失败两次后，改用已验证的 GitHub API 流程，不连续盲重试。

## 使用脚本

本机私密归档：

```powershell
powershell -ExecutionPolicy Bypass -File tools/mistake_archive_fastlane.ps1 `
  -Mode Private `
  -Source "C:\path\to\app.html" `
  -Child eddey `
  -Subject 英语 `
  -Title "英语语法期中试卷分析" `
  -FileName eddey_grammar_midterm_analysis.html
```

公开匿名知识点版，先演练：

```powershell
powershell -ExecutionPolicy Bypass -File tools/mistake_archive_fastlane.ps1 `
  -Mode Public `
  -Source "C:\path\to\anonymous_app.html" `
  -Child kenton `
  -Subject 数学 `
  -Title "小数除法错因分析" `
  -FileName kenton_decimal_division_analysis.html `
  -PrivacyChecked `
  -DryRun
```

确认输出无误后去掉 `-DryRun`；用户明确要求发布时再加 `-Publish`。脚本会先同步远端、拒绝覆盖已有不同文件、更新独立错题档案索引并执行提交推送。

## 完成定义

- 用户拿到的是可运行软件，不是效果图或操作说明。
- 首页对应孩子下方能进入错题档案。
- 公开版点卡片直接打开；私密版导入一次后能在当前设备直接打开。
- 错题弹层、重点教学、再练、连续答对两次归档和导出至少各验证一次。
- 最终回复只给结果、直达入口、验证状态和确实存在的限制，不复述长过程。
