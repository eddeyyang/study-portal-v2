# 暑假英语学习馆归档规则

`apps/summer_english_hub.html` 是哥哥 Kenton 与弟弟 Eddey 的暑假英语统一主入口；目录数据在 `data/summer-english-library.json`。

以后用户在任意对话中说“更新到哥哥/弟弟暑假学习库”“放进暑假英语学习馆”或相近表达时，按以下规则执行：

1. 先锁定孩子，只能是 `kenton` 或 `eddey`。无法可靠判断时只问孩子是谁，不混用两人的软件和记录。
2. 再判断分类：
   - `learning`：预习、复习、知识讲解、互动实验室、错点重教、口语学习等以“教会”为主的软件；
   - `dictation`：自动报默、听写、默写任务、错词重默等以“写出并核对”为主的软件。
   - 同一软件兼有两种能力时，看本次任务的主要目的；必要时可用不同 `id` 在两个分类各登记一条，但不能把普通学习软件全部塞进默写。
3. 日期按北京时间 `Asia/Shanghai`、格式 `YYYY-MM-DD`。优先使用实际上课/作业/材料日期；没有材料日期时才用入库日期。
4. 每条使用稳定且唯一的 `id`，更新同一条目时保留 `id`；不要因再次上传而重复造一条。
5. 新软件放入 `apps/`，同时登记：
   - `data/apps.json`：全站软件库索引；
   - `data/summer-english-library.json`：暑假英语馆的孩子、分类和日期索引。
6. `data/summer-english-library.json` 必填字段：`id`、`child`、`kind`、`date`、`title`、`summary`、`file`、`source`、`tags`；最近必须做的任务可加 `featured: true`。
7. 共用软件可以分别登记给两个孩子，但软件内部的学习进度、错词本和导出数据仍必须按孩子隔离。
8. 页面按日期倒序显示，不删除旧版本的历史条目；真正替换软件时更新同一条目的文件和说明。

完成更新后必须校验 JSON、检查索引中的文件真实存在，并从首页走一次：`暑假英语学习馆 → 选择孩子 → 学习/默写 → 打开软件`。
