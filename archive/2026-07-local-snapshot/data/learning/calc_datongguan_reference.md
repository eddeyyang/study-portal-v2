**第1讲 颠倒数的加法（完整，p2–6）**
- 真题：58+85=143。放大镜：首尾颠倒/两位数/相加求和。
- 解析：58+85=(5+8)×11【首尾和×11】=13×11【化加为乘】=143【乘11：两边一拉中间相加】。
- 公式：**和=(首+尾)×11**。口诀：**首尾相加两边拉，两边相加放中间**。
- 训练：56+65、48+84；（和一位连写两个）35+53、27+72；（和为10，0占个位）46+64、19+91。
- 变式：①三位颠倒数（各位和相等）：首尾相加两边一拉、两边再加中间双插（468+864=1332、579+975=1554）②和是一位数连写三个（234+432=666、543+345=888）③中间有0：首尾和进位连写两个（507+705=1212、806+608=1414）。

**第2讲 颠倒数的减法（完整，p7–11）**
- 真题：72−27=45。解析：=(7−2)×9【首尾差×9】=45【化减为乘】。公式：**差=(首−尾)×9**。
- 位值证明（可做动画）：(7×10+2)−(2×10+7)=(7−2)×10+2−7=(首−尾)×9。
- 训练：73−37、91−19；（三位中间同：×99）936−639、723−327；（四位中间两位同：×999）4362−2364、6251−1256。
- 变式（互补数相减，和=100/1000/10000）：**差=(被减数−50/500/5000)×2**：73−27=46、61−39=22；613−387=226、542−458=84；7261−2739=4522、8043−1957=6086。

**第3讲 被减数是100、1000……的减法（完整，p12–16）**
- 真题：100−58=42。口诀：**前面用9减，末位用10减**（十位 9−5=4，个位 10−8=2）。
- 训练：100−37、100−65；（减数中间有0，差对9）1000−406=594、10000−8053=1947；（减数首位9，差首位0不写）1000−976=24、10000−9841=159。
- 变式：①减数少两位→差首位写9（1000−78、1000−55）②减数中间连续几个0差对几个9（1000−403、10000−8006）③减数中间连续几个9差对几个0（1000−292、10000−7994）。

**第4讲 任意数乘5（完整，p17–21）**
- 真题：32×5=160。解析：=32÷2×10【偶数÷2×10】=16×10【折半添0】。口诀：**添0取半**。
- 公式：偶数×5=÷2×10；奇数×5=×10÷2；整十数×5=折半后添1个0。
- 训练：84×5、126×5；（奇数）37×5、211×5；（整十）460×5、780×5。

**第4讲 任意数乘5（尾页+笔记页，p20–21）**
- 思路（笔记页）：偶数×5=先÷2再×10；奇数×5 同理（先×10 再÷2）。
- 变式：×25 = ×100÷4（84×25、122×25）；×125 = ×1000÷8（32×125、432×125）；×55 = 添0取半乘11，即 ×10÷2×11（48×55、114×55）。

**第5讲 一个数除以5（完整，p22–26）**
- 真题：420÷5。放大镜：个位是 0 的数 ÷5；两数相除。
- 解析：420÷5 = 42×2【去 0 再乘 2】= 84。公式：被除数÷10×2=商。口诀：**去 0 再乘 2 直接出答案**。
- 训练：210÷5、320÷5；（个位是5：×2再÷10）215÷5、145÷5；（整百）200÷5、1000÷5。
- 变式：①÷25=去两个0乘4（2200÷25、3200÷25）②÷125=去三个0乘8（47000÷125、12000÷125）③0不够先乘后去0（325÷25、1500÷125）。

**第6讲 交叉相乘法·两位数×两位数（完整，p27–30）**
- 真题：14×42=588。口诀：**尾数相乘 → 对角相乘再相加（满十进位）→ 首数相乘**。
  （4×2=8 定个位；1×2+4×4=18 定十位并进 1；1×4+1=5 定百位。）
- 训练：23×12、33×21；（满十进位）32×24、21×17；（末尾有0）26×30、34×80。
- 变式：①接近整百用补数法：一个数减另一数的补数写前面、补数相乘写后面（86×97、89×92）②相同乘数照用（46×46、52×52）③末尾有0：0前的数相乘再添0（90×20、70×90）。

**第7讲 十几乘十几（完整，p32–36）**
- 真题：16×17=272。口诀：**尾数相乘（满十进位）写个位，前面的乘数+后面乘数的尾数（加进位）写前面**（6×7=42 写2进4；16+7+4=27）。
- 训练：12×13、12×14；（满十进位）15×17、19×18；（尾数0占位）12×15、15×14。
- 变式（一百几十相乘=去0算再添两个0）：①不进位 120×130、120×140 ②进位 160×170、140×190 ③十位积末尾是0（结果至少3个0）120×150、150×180。

**第8讲 九十几乘九十几（完整，p37–41）**
- 真题：92×97=8924。口诀：**一个数减另一个数的补数写在前，补数相乘写在后（不足10补0）**（补数8和3：92−3=89 或 97−8=89；8×3=24）。
- 训练：97×95、94×93；（补数积不满十补0）99×99、98×96；（差有0不能丢）92×98、94×96。
- 变式：①一个乘数是九十几的一半：按九十几×九十几算再÷2（92×48、49×94）②九十几×一百零几：积=(九十几+剩余数)×100−补数×剩余数（92×103、95×106）③带0先去0再添回（940×97、950×930）。

**第9讲 任意数乘11（完整，p42–46）**
- 真题：34×11=374。口诀：**两头一拉，中间相加**（3和4拉到两边，3+4=7放中间）。
- 训练：24×11、63×11；（中间满十进一）38×11、49×11；（相加是10写0占位）46×11、19×11。
- 变式：①三位数×11："两边一拉，中间两两相加"（123×11、453×11）②多位数有进位（468×11、975×11）③几百零几×11：首尾各写两遍（507×11、806×11）。

**第10讲 个位数相同的两位数相乘（完整，p47–51）**
- 真题：12×32=384。分层竖式：十位×十位=3、个位×个位=4（不满十中间补0）→304；(十位+十位)×个位=(1+3)×2=8 写十位 →+80=384。
- 口诀：**十位积放前、个位积放后（不满十补0），中间加（十位和×个位）**。
- 训练：23×53、64×34；（个位都是1）21×31、71×91——口诀"头×头写前，头+头写中（满十进一），尾×尾写后"；（个位都是9）49×69、39×89。
- 变式（末尾有0：去0算再添0）：210×51、38×480；390×590、540×240；5700×170、860×2600。

**第11讲 十位数相同的两位数相乘（完整，p52–56）**
- 真题：61×63=3843。分层竖式：6×6=36 接 1×3=3（不满十补0）→3603；(个位和)×十位=(1+3)×6=24 补0→240；相加=3843。
- 口诀：**十位相乘积写前面，个位相乘积接上；个位求和乘十位，补0再加前数**。
- 训练：49×46、38×34；（个位积不满十补0）72×74、41×48；（个位积是几十0占位）65×68、82×85。
- 变式（同第10讲：去0再添0）：210×28、43×480；520×510、350×340；1700×160、260×2300。

**第14讲 头同尾合十（完整，p67–71）**
- 真题：24×26=624。口诀：**头×(头+1) 放前面；尾×尾 放后面**（2×3=6；4×6=24）。
- 训练：56×54、48×42；（尾积不满十0占位）81×89、79×71；（尾数5的平方）45²、65²。
- 变式：①连乘构造 4×42×12、64×22×3 ②运算律构造 29×42、36×21+36×13 ③带括号先算 43×(99−52)、82×(38+50)。

**第15讲 尾同头合十（完整，p72–76）**
- 真题：63×43=2709。口诀：**头×头+尾 放前面；尾×尾 放后面**（6×4+3=27；3×3=9 → 27|09，尾积不满十0占位）。
- 训练：31×71=2201、12×92=1104；（尾积满十直接用）29×89=2581、14×94=1316；（头尾都合十）45×65=2925、25×85=2125。
- 变式：①连乘构造 2×42×31=2604、28×44×2=2464 ②运算律构造 29×178=5162、63×22+63×21=2709 ③带括号 44×(100−36)=2816、36×(66+10)=2736。

**第16讲 合十数乘重复数（完整，p77–80）**
- 真题：37×55=2035。口诀：**(合十数的头+1)×重复数的头 放前面；尾×尾 放后面**（(3+1)×5=20；7×5=35）。
- 训练：37×66=2442、82×88=7216；（尾积不满十补0）73×22=1606、82×44=3608。
- 变式（构造合十数）：42×33+31×33=2409、87×66−41×66=3036。

**第12讲 多位数乘9的重复数（完整，p57–61）**
- 真题：7×999=6993。口诀：**去 1 添补，中间插位数差个 9**（首=7−1=6；尾=补数 10−7=3；中间插 2 个 9）。
- 补数规则：三位数用 1000 减、四位数用 10000 减；补数位数不够前面添 0。
- 训练：12×999、46×99999；154×9999、1837×99999；（补0）98×999、998×9999。
- 变式：①位数相同照用（586×999、1387×9999）②9 的位数少："去1去头添尾补"（4176×999、53276×999）③连乘组合出 9 的重复数（16×111×9、3333×4138×3）。

**第13讲 重复数乘9（完整，p62–66）**
- 真题：66×9=594。口诀：**尾数相乘两边拉，中间插 9 补足**（6×9=54 拆到两端，中间插 位数−1 个 9）。
- 训练：55×9、88×9；444×9、333×9；6666×9、88888×9。

## 方法篇 16 讲（第 5–16 讲有正文全档；第 1–4 讲有全套分步答案）

### 第1讲 拆补凑整法（正文已补齐 p82–86）
- 真题：11+7+89+3=(11+89)+(7+3)【互补配对】=100+10=110【相加求和】。放大镜：存在互补数（和为整十百）；结合相加。
- 题干特点：①互补数 ②全部相加。技巧：**找互补，交换结合求和**。提示语：尾数相加为十即互补；互补数不相邻可交换；大数先看最后两位。
- 训练+答案（分步全档）：9+1+36+64=(9+1)+(36+64)=110；36+64+87+13=200；129+67+71+33=(129+71)+(67+33)=300；258+43+57+42=400；951+631+49+69=(951+49)+(631+69)=1700；134+264+66+236=700。
- 变式：①凑整补差 29+19+9+4=(29+1)+(19+1)+(9+1)+1=61；199+98+7+6=(199+1)+(98+2)+(7+3)=310 ②28+18+8=(28+2)+(18+2)+(8+2)−6=54；499+298+97=894 ③加减混合配对 131−12−31−28=(131−31)−(12+28)=60；174−(28+74)−72=(174−74)−(28+72)=0。

### 第2讲 带符号搬家（1）（正文已补齐 p87–91）
- 真题：128−65+72=128+72−65【带符号搬家】=200−65=135【相减求差】。
- 特点：①多个数相加减无括号 ②加法尾数能凑整或减法尾数相同。方法：数带着前面的符号搬家。
- 训练：36+72+64=36+64+72=172；136+87+64=287；129+67−29=129−29+67=167；258+43−158=143；149−63+51=149+51−63=137；256−78−56=256−56−78=122。
- 变式（小数同样适用）：66.7+2.4+3.3=72.4；7.9+13.8+2.1=23.8；19.4−3.8−3.4=12.2；23.7−9.5−3.7=10.5；18.7+2.5−2.7=18.5；24.6−6.9+5.4=23.1。

### 第3讲 添去括号法（1）（正文已补齐 p92–96）
- 真题：67+56+24=67+(56+24)【添加括号】=67+80=147【相加求和】。公式：a+b+c=a+(b+c)。
- 特点：①多个数相加减（无/有括号）②加法尾数能凑整或减法尾数相同。变号口诀：＋号后添/去括号不变号，−号后全变号。
- 训练：34+72+38=34+(72+38)=144；87+36+64=187；129+67−47=129+(67−47)=149；58+43−43=58；49+(51+63)=49+51+63=163；56+(244−70)=56+244−70=230。
- 变式：89−23+13=89−(23−13)=79；67−29+19=57；143−46−24=143−(46+24)=73；138−59−21=58；231+(69−50)=231+69−50=250；154−(54−36)=154−54+36=136。

### 第4讲 基准数法（正文已补齐 p97–98）
- 真题：47+49+52+53+55=50−3+50−1+50+2+50+3+50+5【找基准数】=50×5−3−1+2+3+5【变加为乘】=250+6=256。
- 公式：**和=基准数×个数+调整数**。特点：①多个数相加 ②加数都接近同一个数。
- 训练提示语（p99）：根据基准数快速确定调整数；认真观察排序，有时带符号搬家更简单。
- 变式（p100）：①存在约为基准数2倍的大数→拆成与基准数相近的数（37+39+45+43+78、83+79+78+80+161）②两个较小数之和接近基准数→先求和（25+19+23+18+9+12、132+130+128+129+61+63）③求平均数：**平均数=基准数+调整数÷个数**（(23+18+19+25+20)÷5、(53+51+49+54+55+50)÷6）。
- 训练：32+33+29+30+35=30×5+9=159；82+79+84+80+76=80×5+1=401；23+20+19+22+18+21=20×6+3=123；306+299+303+296=300×4+4=1204；102+100+99+101+98=100×5=500；53+50+49+51+48+47+52=50×7=350。
- 变式：①拆数凑基准 37+39+45+43+78=37+39+45+43+38+40=40×6+2=242；83+79+78+80+161=80×6+1=481 ②25+19+23+18+9+12=25+19+23+18+21=20×5+6=106；132+130+128+129+61+63=130×5−7=643 ③求平均 (23+18+19+25+20)÷5=20+5÷5=21；(53+51+49+54+55+50)÷6=50+12÷6=52。

### 第5讲 连续自然数求和（原书103–106）
- 放大镜：数字＝连续自然数；算法＝全加。特点：①连续自然数相加 ②相邻差1。
- 例题：1+2+…+100=(1+100)+(2+99)+…+(50+51)【首尾相加定组数】=101×50【变加为乘】=5050。

### 第6讲 分组法（107–111）
- 放大镜：连续自然数；加减交替。例题：16−15+14−13+12−11+10−9=(16−15)+(14−13)+(12−11)+(10−9)【相邻组合定组数】=1×4【变加为乘】=4。

- 变式：①减加规律 1−2+3−4+…+9=1+(3−2)+(5−4)+(7−6)+(9−8)=5；1−2+3−…−20+21=1+1×10=11 ②去括号再分组 (2+4+6+8+10)−(1+3+5+7+9)=(2−1)+(4−3)+…=5；(2+4+…+50)−(1+3+…+49)=25 ③多数一组 3−4−5+6+7−8−9+10=(3+6−4−5)+(7+10−8−9)=0；…+35−36−37+38=0。

### 第10讲 添去括号法（2）（乘除，127–131）
