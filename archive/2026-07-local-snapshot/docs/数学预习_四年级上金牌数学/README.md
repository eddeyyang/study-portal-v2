## 全书核心知识一览（预习软件·速查）

- **运算律五大定律**：加法交换律 a+b=b+a；加法结合律 (a+b)+c=a+(b+c)；乘法交换律 a×b=b×a；乘法结合律 (a×b)×c=a×(b×c)；乘法分配律 (a+b)×c=a×c+b×c（含 5 条推广公式）。
- **运算关系**：加数+加数=和、被减数−减数=差、因数×因数=积、被除数÷除数=商……余数；乘除互逆、加减互逆。
- **四则运算顺序**：先乘除后加减；有小括号先算小括号，再中括号；同级从左往右。
- **应用题方法**：综合法、分析法、假设法、逆推法（还原问题）、画图法；工作效率三量关系。
- **大数**：数位顺序表（个级/万级/亿级）、读写规则（0 的处理）、改写（万/亿）、四舍五入求近似数、逆推近似数范围（最大 304999 / 最小 295000 型）。
- **分数**：几分之一/几分之几、分数各部分名称、同分母比分子、同分子比分母、同分母加减（分母不变分子相加减）、1 减几分之几、整体是一些物体时的 a 是 b 的几分之几、求一个数的几分之几。
- **几何**：线段/射线/直线区别；圆心、半径、直径（d=2r）、圆规画圆、等圆与同心圆；角的定义与表示、度量（量角器）、分类、画角、三角形内角和 180°、多边形内角和分割法；尺规作图。
- **方向**：八方向（东、南、西、北、东北、东南、西北、西南）、方向相对性、风向标原理。
- **数学思想**：抽屉原理（至少数=商+1，有余数时）、列表枚举、鸡兔同笼。
- **培优三专题**：错中求解、多次相遇问题（第 n 次相遇共走 (2n−1) 个全程）、位值原理（差必是 99 的倍数）。
