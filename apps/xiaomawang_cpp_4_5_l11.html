实验 4 · 奇偶分拣机（if-else 双分支）

奇数走左边，偶数走右边

n % 2 == 1 ?
odd 奇数
even 偶数
if (n % 2 == 1) { cout << "odd"; } else { cout << "even"; }
💡 if-else 是双分支：成立走 if，不成立走 else，必走其一。else 不能单独出现，必须跟在 if 后面！快捷写法（三目运算符）：n%2==1 ? cout<<"odd" : cout<<"even";
