➕ 循环累加放大镜
方法回顾：在 for 循环里放 cin，就能多次输入不同的数；每一轮都是"输入 → 累加进 sum → 输出"三步。sum 像个存钱罐，每轮把新数丢进去，越攒越多。
int sum=0; int a; for(int i=1;i<=3;i++) {   cin>>a;   sum=sum+a;   cout<<sum<<endl; }

🚪 if 嵌套 if · 透视镜
方法回顾：if 语句是一个整体——小括号条件成立才执行大括号。大括号里的 if 也是一个整体，轮到它时同样看条件。关键是看清每句话在哪层大括号里：p 和 c 在外层，w 在内层。
if(a>20) {   cout<<"p"<<endl;   if(b<20)   {     cout<<"w"<<endl;   }   cout<<"c"<<endl; }

🌲 if-else 嵌套 · 选路轨道
方法回顾：if 语句是选择结构——选择执行一部分之后就结束了，不会每个部分都执行。看复杂 if 时，盯住每一个 if 在哪两个大括号之间做选择：外层在「a>20 的括号」和「else 的括号」二选一；进了外层，内层再在 af 和 w 里二选一。
if(a>20) {   if(b>20){ cout<<"af"<<endl; }   else{ cout<<"w"<<endl; } } else{ cout<<"rh"<<endl; }
a = 25　b = 15
课堂原题：a=25 进外层 → b=15 不满足 b>20 → 走内层 else，输出 w。挑战：怎么调滑块能让小球滚到 af？滚到 rh？
🖨 循环输出 i 的值 · 打印机
方法回顾：for(int i=2;i<=5;i++){ cout<<i; } 里，i 从 2 开始每轮自增 1，i 是 2,3,4,5 时条件成立、各印一次。改初始值和判断条件，就能印出任意一段连续整数——拖两个滑块马上看到！
for(int i=2; i<=5; i++){ cout<<i<<endl; }
初始值 = 2　条件 i ≤ 5

例题 1 · 循环输入 & 变量累加（输入 1、2、4 → 输出 1、3、7）
int sum=0;　// 新建存钱罐 sum，先放 0 int a;　// 新建变量 a，装每轮输入的数 for(int i=1;i<=3;i++)　// 重复 3 次：i 从 1 数到 3，每轮加 1 {   cin>>a;　// 键盘输一个数，装进 a   sum=sum+a;　// 把 a 加进 sum 再放回（可简写 sum+=a）   cout<<sum<<endl;　// 印出现在的 sum，换行 }
例题 2 · if 嵌套 if（a=25、b=15 → 输出 p、w、c）
int a,b;　// 同一行新建两个变量 cin>>a;　// 输入 25 cin>>b;　// 输入 15 if(a>20)　// 外层门：25>20 成立，进大括号 {   cout<<"p"<<endl;　// 在外层里，必印 → 输出 p   if(b<20)　// 内层门也是一个整体：15<20 成立   {     cout<<"w"<<endl;　// 内层成立才印 → 输出 w   }   cout<<"c"<<endl;　// 内层外面、外层里面 → 输出 c }
例题 3 · 循环输出 i 的值（输出 2、3、4、5）
for(int i=2;i<=5;i++)　// i 从 2 开始，i≤5 就继续，每轮自增 1 {   cout<<i<<endl;　// 印出这一轮 i 的值 → 2 3 4 5 }
