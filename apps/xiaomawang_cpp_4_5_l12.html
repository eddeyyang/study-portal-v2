实验 1 · 多分支阶梯

a 和 b 谁大？三种情况走三扇门

if (a > b) { cout << ">"; } else if (a < b) { cout << "<"; } else { cout << "="; }
选两个数，看走哪扇门！
💡 多分支从上往下逐个检查：表达式 1 成立做事 1；否则看表达式 2；都不成立才走 else。注意 else 只跟它前面最近的那个 if 配对。

实验 3 · 字符判断机

'A'、'a' 还是 other？

字符要用单引号引起来，而且单引号里只能有一个字符。按键盘试试：

char ch; cin >> ch; if (ch == 'A') { cout << "A"; } else if (ch == 'a') { cout << "a"; } else { cout << "other"; }
点一个字符按键！
