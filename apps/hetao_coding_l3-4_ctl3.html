CTL 专项课 3

三类必背代码框架

先用自己的话说“这一段要做什么”，再点开并揭开白话翻译。不是背符号，而是背程序结构。

① 输入 → 计算 → 输出
#include <iostream> using namespace std; int main(){ int a,b,ans; cin >> a >> b; ans=a+b; cout << ans << endl; return 0; }
白话：准备两个整数盒子 → 从左到右装入 → 先算右边 → 把结果放进 ans → 输出。
② if / else 二选一
cin >> t; if(t>30){ cout << "swim"; } else { cout << "climb"; }
白话：先判断条件。成立只走 if 这条路；不成立只走 else。t=30 时，30>30 不成立，所以输出 climb。
③ for 重复执行
for(int i=6;i<=10;i++){ cout << i << endl; }
白话：i 从 6 出发；只要 i 还不超过 10 就输出；每圈结束 i 加 1，再回去判断。
课堂重点

输出 6 到 10 的两种写法

方法 A · i 直接当答案
for(int i=6;i<=10;i++) cout<<i;

起点直接设为 6，走到 10。

方法 B · i 当计数器
for(int i=0;i<5;i++) cout<<i+6;

i 走 0、1、2、3、4，输出时统一加 6。

共同点：两段都执行 5 次，最后都输出 6、7、8、9、10。写完先问：一共需要几个数？
