✨ sum += a 变身器
方法点拨：sum=sum+a 里，等号左右都有 sum——数学里没这种写法，编程里却常用：把 sum 加上 a，再放回 sum。因为太常用，C++ 给了个缩写：sum += a。两种写法功能完全一样。
sum = sum + a;
点「变身」：右边的 sum 缩进等号里，+ 和 = 挤在一起 → sum += a;
⌨️ 循环输入 + 求和（两种写法一起跑）
重点难点预演！for 里放 cin，每轮输一个数、加进 sum。左右两段代码只有那一行不一样，点数字喂 3 个数，看它们算出的 sum 是不是一样。
写法 A：sum = sum + a
int a, sum=0;for(int i=1;i<=3;i++){ cin>>a; sum = sum + a;}
sum = 0
写法 B：sum += a
int a, sum=0;for(int i=1;i<=3;i++){ cin>>a; sum += a;}
sum = 0
第 1 / 3 轮，点一个数喂给两边的 cin：
每点一个数，两边同时执行"输入 → 加进 sum"。看好了：结果永远一样！
🚪 双重门城堡 · 多 if 嵌套
方法点拨：if 里面再放一个 if，就是 if 嵌套。像闯城堡：先过外面那道门（外层 if），才有资格走到里面那道门（内层 if）跟前。外层不成立，里层连看都不会被看一眼。
if(a>10)　// 第一道门 {   if(b>10)　// 第二道门   {     cout<<"win";　// 拿到宝石   } }
a = 15　b = 6
门1：a>10
门2：b>10
🤺 💎
拖两个滑块设 a 和 b，再让骑士出发。两道门都开才能拿到 💎。
🤝 if 嵌套 vs &&，是双胞胎！
方法点拨：上学期学的 &&（与，两边都成立才成立）还记得吗？if 嵌套两道门 = && 把两把锁装在一道门上。下面两段代码，不管 a、b 是几，结果永远一样。
嵌套写法：两道门
if(a>10){ if(b>10){  cout<<"win"; }}
→ ?
&& 写法：一门双锁
if(a>10 && b>10){ cout<<"win";}
→ ?
a = 12　b = 12
拖滑块试各种组合：两边都>10 才 win。结论：两段代码永远同生同死——这就是明天课上的"if 嵌套 ↔ && 改写"。
🧮 数学连接：编程的 && 就是数学里的"且（∧）"。a>10 且 b>10，两个条件同时满足。
🌲 if-else 嵌套 · 分数分岔树
方法点拨：else 里面再套一个 if-else，就能连着分好几岔。执行顺序：从上到下，第一个条件成立就走那条岔，后面的全部不看；不成立才继续往下一个条件。永远只走到一个出口。
if(score>=90){ cout<<"great"; } else {   if(score>=60){ cout<<"pass"; }   else{ cout<<"fight"; } }
分数 score = 75
拖滑块改分数，再让小球滚。看它在每个岔口怎么选路——只走一条，绝不回头。
🔮 for 里的 cout-if 预言机
方法点拨：for 里同时放 cout 和 if 时，每一轮都要把大括号里的内容从头到尾走一遍：cout 每轮必执行，if 只在条件成立的那几轮才多输出。先自己猜猜输出，再一步步验证！
for(int i=1; i<=5; i++) {   cout<<"a";　// 每轮必印   if(i>3){ cout<<"b"; }　// i>3 才印 }
