🛤️ if-else 选路轨道 if-else 嵌套 if-else
if 语句是选择结构：选择执行一部分之后就结束了，不会每个部分都执行。看小火车 🚂 走哪条轨道（讲义例子：a=25，b=15）。
if(a>20) // a=25 ✔ 成立
{
if(b>20) // b=15 ✘ 不成立
{ cout<<"af"<<endl; }
else // ✔ 走这里
{ cout<<"w"<<endl; }
}
else // 外层已选，跳过
{ cout<<"rh"<<endl; }
🚂起点：if(a>20)a=25，成立 → 进站
🔀岔路：if(b>20)b=15，不成立 → 走 else
🚫cout<<"af"被跳过
✅else：cout<<"w"输出 w！
🏁外层 else（"rh"）选择已结束，不经过

⚙️ for 运行过程慢放机 循环三要素 · 下节课重点
for 小括号里有三要素，它们按固定顺序转圈：①初始化（只做一次）→ ②判断条件 → 成立就 ③执行大括号 → ④步长 i++ → 回到 ②再判断……直到条件不成立，循环结束。

🥊 擂台法找最大值 复习 + 拓展
擂台上先站第一个数当"擂主"（max=a），后面的数一个个上来挑战：挑战者 > 擂主，就换新擂主；否则擂主不动。打完全场，擂主就是最大值！
cin>>a>>b>>c; // 153 410 410
int max=a; // 擂主先站 a
if(b>max) max=b; // b 挑战
if(c>max) max=c; // c 挑战
cout<<max<<endl;
终端区
👉 点「开赛」。想一想：c=410 和擂主 410 一样大，能抢走擂台吗？（不能！> 才行，一样大不算赢）
🔀 && 和 || 判断器 与 / 或 的执行规则
两个条件怎么合起来算？
🔗 &&（与）：两边都成立，整体才成立——像两扇都要开的门。
🌈 ||（或）：只要有一边成立，整体就成立——像两条路任选一条。
点开关切换条件成立/不成立，再切换运算符看看！
条件①5 > 3
条件②2 > 4
整个条件(5>3) && (2>4)
💡 灯亮 = 条件成立。整体成立，if 大括号里的代码才会执行。
