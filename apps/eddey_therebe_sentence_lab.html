先讲懂

There be 到底在说什么？

There be = 某地有某物。它不是“那里是”，而是在报告“有东西存在”。先看 be 后面第一个名词，再决定用 is 还是 are。

There is后面最近的是一个人/物，或不可数名词。
There is a book.
There is some milk.
There are后面最近的是两个或更多人/物。
There are two books.
否定句is → isn't，are → aren't；some 通常变 any。
There aren't any books.
🐯
Eddey 口诀：别数全车，先看车头！离 be 最近的是单数/不可数，用 is；最近的是复数，用 are。

变化规则

肯定句怎样变否定句？

There are some flowers in the garden.
➜
There aren't any flowers in the garden.
在 be 后面加 not：is not / are not，也可缩写 isn't / aren't。
否定句里，some 通常换成 any。
一般疑问句把 be 搬到最前：Are there any flowers?
先找发动机

一句话，先判断是哪一队

变句型前先圈出发动机。三队的变法不同，认对队伍就不会乱加 do/does。

① be 队：am / is / are
② 情态队：can / should
③ 普通动词队：like / play / watches… → 请 do / does 来帮忙
🔍
检查顺序：先找 be；没有再找 can/should；都没有，才看普通动词。一般现在时主语是 he/she/it 或一个人时，用 does。
句子变形机

为什么这样变

三队变形对照

be 队：否定就在 be 后加 not；提问就把 be 搬到主语前。She is → She isn't → Is she…?
can/should 队：规则和 be 很像。He can → He can't → Can he…?
普通动词队：请 do/does 帮忙；does 出现后，原动词必须恢复原形。likes → doesn't like；watches → Does… watch?
教材中的特殊疑问句：先选 Who / What / When 等疑问词，再接相应的提问结构。例如 Who is she?、What do you like to eat?、When do you usually get up?。软件再加入同结构的 Where are the books? 帮助迁移。
