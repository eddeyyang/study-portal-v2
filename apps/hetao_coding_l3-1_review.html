🧮 多变量运算 · ans = a*2 + b + c*3
方法点拨：好几个变量可以一起算！运行过程还是那两步：① 按"先乘除后加减"算出等号右边 → ② 把结果赋值给左边的 ans。

🥊 擂台法找最大值
方法点拨（擂台法）：max 是擂主。先让 a 当擂主（max=a），之后每个选手都要跟擂主 PK：比擂主大，就成为新擂主（max=b）；比不过就下台。最后站在台上的擂主，就是最大值。
int a,b,c; cin>>a>>b>>c; int max; max=a;　// a 先当擂主 cout<<max<<endl;　// ① if(b>max){ max=b; }　// b 挑战 cout<<max<<endl;　// ② if(c>max){ max=c; }　// c 挑战 cout<<max<<endl;　// ③
a（🐯）= 153
b（🦁）= 410
c（🐼）= 109

💡 为什么中途要 cout 三次？就是让你看清：擂主（max）是一步步换人的。原题输出是 153、410、410——最后 c=109 打不过 410，max 不变。
