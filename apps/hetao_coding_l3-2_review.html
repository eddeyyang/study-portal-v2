🌡️ 游泳还是爬山？（if-else 实战）
赛考真题风格：输入温度 t（1~40），t 大于 30 就去游泳（swim），否则去爬山（climb）。拖温度试试：
今天温度 t = 20 ℃
if(t>30){ cout<<"swim"; } else{ cout<<"climb"; }
🧗
t=20，20>30 不成立 → 走 else → 输出 climb，去爬山。
⚠️ 易错点：t=30 时，30>30 不成立（"大于"不包括相等）→ 还是 climb！赛考最爱考这种边界。
